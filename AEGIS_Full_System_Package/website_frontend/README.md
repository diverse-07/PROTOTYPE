# AEGIS Web Portal (NER-LEWS)

Government command & control GIS monitoring dashboard built for the Ministry of Development of North Eastern Region (MDoNER), NDMA, and state disaster authorities.

## Features:
- Live Interactive Leaflet Map with 16 NER hazard zones (GSI 5-tier scoring)
- Rainfall stress-test multiplier simulation (0.5x to 2.5x)
- Real-time in-situ IoT telemetry (341 sensor nodes)
- Unified Emergency Dispatch Console (NDRF 1st Bn Guwahati, NH-44 highway gates, civil hospitals)
- Automated Citizen Safety Check & live weather telemetry
- Model analytics: 89.3% accuracy, 0.92 ROC-AUC, 2.3s latency

## Quick Start:
```bash
npm install
npm run dev
```
Runs at `http://localhost:5173`
